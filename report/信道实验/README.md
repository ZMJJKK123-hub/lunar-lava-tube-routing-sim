# 信道实验 —— 文件与数据字段大白话手册

## 这个实验在回答什么问题？

同一张地图、同一套消息流，**唯一不同的变量是"每跳消息选哪个信道(频道)"的脑子**：

- **A 组**：手写规则（连续3跳不同频道 + 避开忙碌频道，上帝视角全局规划）
- **B 组**：逐边 Q-learning（每条边一张打分表，只看本地，靠送达奖励/超时惩罚自学）
- **C 组**：纯随机掷骰子（阴性对照——用来检验"信道选择这件事到底重不重要"）

三组走路的算法（Dijkstra 最短路）完全相同，所以比出来的差距**只能来自信道决策**。

## 每个文件是什么

| 文件 | 一句话说明 |
|---|---|
| `comparison_ABC.md` | **★ 最终结论报告**（n=5 轮、压力负载、配对 t 检验）。只想看结果读它 |
| `collect_baseline.py` | 采集器：连上服务器→重置世界→按设定注入消息流→逐帧记录→落盘 |
| `run_abc_batch.py` | 批量执行器：自动跑"重启服务器→跑一臂"×15 场，带孤儿清扫/重试/断点续跑 |
| `abc_batch_*.json` | 三臂实验总原始数据：每臂每轮的汇总 + 统计检验结果 |

## 怎么复现

```bash
# 单跑一场（A 组 300 秒、每 0.5 秒一条消息、流量种子 2001）：
python report/信道实验/collect_baseline.py 300 --arm=A --traffic-seed=2001 --load=0.5
# 一键三臂 ×5 轮（约 100 分钟）：
python -u report/信道实验/run_abc_batch.py 5 300
```

## 数据字段说明（单场 json，如 `每轮原始数据/baseline_rcspa_*.json`）

| 字段 | 大白话 |
|---|---|
| `meta` | 这场实验的"身份证"：代码版本、哪一臂、跑了多久、消息发多快、种子 |
| `meta.traffic.seed` | 流量种子——同种子的两场，发的是完全相同的消息序列（配对实验的保证） |
| `summary.ack_admitted` | 服务器点头收下的消息数（发出后对方确认"可以送"） |
| `summary.client_settled.DELIVERED` | **最终送达基站的条数**（客户端逐条点数，最可信） |
| `summary.client_settled.TIMEOUT 等` | 死在路上的条数（超时/缓冲满/重传耗尽） |
| `summary.client_delivery_rate_pct` | 送达率 = 送达 ÷ 已结算 |
| `summary.client_latency` | 送达消息的耗时统计（平均/中位/P95，单位=拍，1拍=0.25秒） |
| `summary.reject_total` | 服务器拒收数（发不出去：无路/太忙） |
| `samples` | 每 5 秒一帧的"体检记录"：覆盖率、存活数、累计送达、（B组）学习器状态 |
| `samples[].eps` | （仅B组）探索率——还在"乱试"的程度，从 0.3 一路降说明在学习 |
| `samples[].qe` | （仅B组）打分表条数——越长说明见过的"局面"越多 |
| `raw_settlements` | **每条消息的单独成绩单**：几点几秒发出、几拍送到、重传几次（原始数据，可任意重新统计） |
| `latency_first_third / last_third` | 前 1/3 时段 vs 后 1/3 时段的平均耗时——对比可见学习是否越跑越快 |
| `rl_final` | （仅B组）收工时学习器快照：探索率/表规模/近期平均奖励 |

## 每轮原始数据/ 里 68 个文件怎么认

文件名 = `组名_日期_时间`，三种种族对应三臂：

- `baseline_rcspa_*` = A 组（规则）—— 5 场
- `rl_qlearning_*` = B 组（学习）—— 5 场
- `random_channel_*` = C 组（随机）—— 5 场

同一场"轮次"的三臂共享流量种子（如 2001），文件内 `meta.traffic.seed` 可查。
每个 `.md` 是当场的三行小结；`.json` 是全量原始数据。

## 结论速览（详见 comparison_ABC.md）

- 三组送达率全部 100%（负载仍不足以打出丢包差异）
- **平均耗时：B(6.90拍) < A(7.30) ≈ C(7.32)**，配对 t 检验 B 显著优于 A 和 C
- C≈A 是关键发现：**手写信道规则实际没带来超出随机的收益；学习是唯一有效的信道策略**
