## 一分钟看懂三个实验

1. **信道实验**：同一张地图、同一套消息，只换"选频道的脑子"——
   手写规则(A) / 逐边Q-learning(B) / 纯随机(C)。结论：学习版最快且统计显著。
2. **自愈实验**：往网络里砸六种故障，掐表算恢复时间；批量杀节点画鲁棒性曲线。
3. **道钉实验**（用户自建）：对比"见到孤岛就投钉(规则)" vs "学会何时投何时忍(Q-learning)"。
