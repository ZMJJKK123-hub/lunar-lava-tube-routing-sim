# 🌒 月球熔岩管多智能体网络沙盘(纯 2D 简洁版)

前后端分离的实时数字孪生:**纯 2D 极简网络沙盘** —— 一张干净的深空画布(`#0A0F1A`)+ 60 个节点 + 16 块互不重叠的实心巨石。后端逐帧运行全部算法(多智能体 Dijkstra 路由 / RCSPA 资源约束最短路径 / PAMAS 节能状态机 / 物理层链路预算 / 事件解说);前端为纯 Canvas 2D 渲染引擎(60FPS,静息层离屏缓存)。

> 旧 3D 方案与多腔室溶洞地质已废弃;代码保留未挂载。

## 2D 场景(纯简洁)

- **背景**:纯 `#0A0F1A` 深空色,无网格/图案;腔室为**横向扁长的椭圆**(熔岩管平面示意,约 2.2:1),以极淡描边+暗色填充勾出轮廓,腔外即岩壁。
- **巨石**:16 块互不重叠的实心岩石(0.92 不透明 + 亮描边 + 裂纹),可拖拽。
- **遮挡规则一句话**:两节点的直线被石头挡住 → 图中无边,必须中继绕行。

## 视距(LOS)架构 —— "看不到 → 图中无边 → 必须中继"

后端对每对节点做严格 2D 射线检测:**线段-圆相交**(巨石/巨柱)+ **管内采样**(线段必须全程在腔室/通道体积内)+ **用户墙体**(2D 线段叉积相交)。任一阻挡 → 该对永不建边,数据只能沿真实存在的边多跳绕行。当前拓扑:83 节点 / 平均度 8.4 / 最深 12 跳 / 363 对被真实几何遮挡。

## 连线渲染(v2 极简静息制)

| 状态 | 样式 |
|---|---|
| 阻断链路 | 不可见,不渲染 |
| **默认静息(全部连线)** | 暗绿实线 `rgba(70,150,100,0.15)`,无发光无动画 —— 若隐若现的暗网 |
| **Hover 激发** | 悬停节点的直连边瞬间变为 `#00FFFF` 全亮 + shadowBlur 外发光,并有波浪脉冲从悬停节点沿边传向邻居;移出即恢复静息 |

静息层缓存于离屏 Canvas,仅数据/视图变化时重绘;未 Hover 时 rAF 只做一次位图拷贝,零动画开销。点击节点在节点旁弹出极客数据面板(ID / 2D 坐标 / SoC / 温度 / SNR / 频段 / 电台状态),右键仍有破坏菜单,巨石仍可拖拽触发全网 LOS 重算。

## 节点战术图标与状态

- 主基站=六边形 / 探测器=菱形 / 道钉=圆+外发光圈;标签 `N-24` 像素风。
- 健康=青色呼吸;低电量/劣化=警告黄;过热=红色扩散波纹;宕机=灰色+红 X。

## 交互(核心)

| 操作 | 效果 |
|---|---|
| 悬停节点 | 科技感 Tooltip:SoC/SNR/温度/BER/路由表/被遮挡邻居清单 |
| 左键节点 | 选中 → 白圈 + 红色虚线 X 标出"看得到却连不上"的邻居 + Inspector 面板 |
| **拖拽巨石** | 松手瞬间后端重算 LOS:被切断的链路从图中消失、主干改道、解说播报"巨石切断了 N 对视线,算法正在重算…" |
| 空白拖拽 | 画墙(2D 线段遮挡),同样实时重算;Shift+拖动=平移;滚轮=缩放 |
| 右键节点 | 菜单:「手动破坏此节点」/「过热测试」/「恢复」 |
| HUD 灾害按钮 | 塌方/热浪/耀斑/摧毁主干道,全程解说员播报 |

## 快速开始

```bash
cd backend && pip install -r requirements.txt && python main.py   # :5000
cd frontend && npm install && npm run dev                          # :5173
```

> 若 `/ws` 404:`pip install websockets`。

## 演示脚本

1. 开场:蓝图上溶洞轮廓 + 暗绿蜘蛛网 + 青色主路流光,机器人金线巡游。
2. **拖巨石砸断青色主干** → 边瞬间消失 → 波纹扩散 → 主干改道亮起 → 解说"网络自愈完成,以 04号 为例,数据在岔路口拐弯…"。
3. 点击节点看红虚线 X(被挡邻居)与 Inspector 硬件参数/电台状态(PAMAS SLEEP/TXRX)。
4. 右键破坏节点 → 灰色+红X → 全网重路由。
5. 画墙实验:拖一堵长墙横切溶洞,观察覆盖率和平均度骤降,清墙复原。
